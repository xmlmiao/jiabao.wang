# Bao 的像素小屋 · jiabao.wang

单文件静态站：`index.html`（无构建、无外部资源）。`CNAME` 用于 GitHub Pages 自定义域名。

房间里有一只会走动的长毛奶牛猫 **Baxa**（点它会喵），墙上挂着一排像素画，窗外会随本地时间变成白天 / 黄昏 / 夜晚。

## 逛小屋

- 房间里的物件与下方按钮共用同一套交互。鼠标移上去会显示名称和像素角标，手机可以直接使用下方的大按钮。
- 所有介绍使用同一种弹窗：右上角关闭、Esc 或点击遮罩退出，点击正文不会误关。关闭后焦点回到入口。
- 画廊可以看完整像素画与照片，用前后按钮或左右方向键翻页。手机竖屏、横屏都限制在视口内，较长内容在弹窗内部滚动。
- 键盘聚焦场景后，用方向键选择物件，Enter / 空格打开；也可以 Tab 到每个按钮。
- 「时光」依次切换自动、白天、黄昏、夜晚。台灯有手动开关，也可以随时光自动亮起。
- 「暂停动画」会冻结整个房间的动画。系统启用减少动态效果时默认暂停，仍可手动继续。

## Baxa 动画

继续使用 `assets/baxa/sheet.png` 原有 10 个 18×14 姿势，不放大猫的本体。采用固定 60 Hz 时间步进，走路缓起缓停，步伐按实际移动距离切换；切回后台页面时不追赶积压时间。

起身、走路、停步、坐下和睡醒有短暂过渡。闲暇时会发呆、躺平、舔毛、睡觉或背对你看风景，约 10% 的活动选择是玩球或钻箱子。眨眼、轻微呼吸、睡眠标记和毛线球独立绘制；玩球姿势校正原图朝向，球始终位于前爪一侧。摸摸它会抬头回应，也可以通过弹窗邀请它玩球。

右侧地板有固定的纸箱小窝，空着时也一直存在。Baxa 会先走到箱子的位置再钻进去，探头时只绘制猫的头部，由固定箱子的前壁遮挡身体；离开时先走出小窝，再恢复活动。点击箱子或「Baxa 小窝」按钮可以叫它回窝、邀请它出来玩，纸箱不再跟着姿势在地板上随机出现。调试参数 `?cat=box` 会直接将 Baxa 放在窝内。

## 添加一幅新的像素画

打开 `index.html`，找到 `const GALLERY = [`，追加一项：

```js
{ title:"作品名", year:"2026", desc:"点击后对话框里显示的介绍\n可以换行",
  palette:{ a:"#ff0000", b:"#00ff00" },   // 一个字符 = 一种颜色
  pixels:[                                // 每行一个字符串
    "aaaaaaaaaaaa",
    "abbbbbbbbbba",
    ...
  ] },
```

- 每个字符一个像素；不在 palette 里的字符（如 `.`）是透明的。尺寸任意，常用 12×12。
- **自动布局**：画框大小按 `pixels` 尺寸自动计算，所有作品在墙面（x 52–152，窗户和书架之间）等间距排开、底边对齐，点击区域也自动跟随，不用手动改坐标。
- **featured**（可选）：加 `featured:true` 的作品会排在正中间并用亮金色画框，适合放一幅更大的主打作品（如 20×20）。
- **图片作品**：用 `{ title, year, desc, img:"assets/gallery/photo.png", thumb:"assets/gallery/photo-thumb.png", w:12, h:12 }` 替代 `pixels` 和 `palette`。缩略图挂在墙上，`img` 用于弹窗大图。
- 墙面宽约 100 像素：4 幅 12×12 很宽松；作品太多或太大时间距会被压到 1px，此时可以减少作品或缩小尺寸。

## 调试参数

- `?phase=day|dusk|night` 强制窗外时间
- `?cat=left|right` 让猫一直朝某个方向走（检查朝向）
- `?cat=sit|stand|walk|lie|sleep|look|groom|play|back|box` 固定查看对应姿势
- `?cloud=edge` 把云固定在窗玻璃右缘（检查裁剪）
